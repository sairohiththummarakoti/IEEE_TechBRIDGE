# IEEE TechBRIDGE Global

Responsive React website for TechBRIDGE Global, a 2027 IEEE Computer Society industry engagement initiative focused on practical, hands-on technology workshops for working professionals.

## Run locally

```bash
pnpm install
pnpm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
pnpm run build
pnpm run preview
```

## Included

- Responsive desktop, tablet, and mobile layouts
- 2027 targets and quarterly program roadmap
- IEEE Computer Society strategic-plan alignment
- Interactive roadmap filters and image gallery
- Host-interest form with client-side validation and success state
- Official IEEE Computer Society web logo asset

## Form integration

The interest form currently provides a front-end success state. Connect the submit handler in `src/App.jsx` to an approved API, CRM, or form service before collecting production submissions.

## Brand assets

The IEEE Computer Society logo is used unmodified. Follow the official [logo policy](https://www.computer.org/publications/logo-policy) and [brand guide](https://www.computer.org/about/ieee-computer-society-brand-guide) for production use.
